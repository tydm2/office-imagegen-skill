# 办公文档提示词库（prompt-library）

面向 PPT / Word / Excel 的生图提示词范式 + 各场景模板 + 避坑。原则：**一句话说清主体 + 风格 + 构图 + 用途 + 约束**。

## 通用公式

```
[主体] + [风格/材质] + [构图与视角] + [配色] + [用途/情绪] + [约束：无文字、无logo、留白]
```

## 各场景模板

### 封面（title，16:9）
> 「{主题}主题封面，{风格：扁平/渐变/科技感/商务}，{主体元素}，{配色}，居中构图，大面积留白，高级简洁，无文字」

例：`科技公司年度战略汇报封面，深蓝渐变背景，抽象几何线条与光点，居中留白，商务高级感，无文字`

### 章节页（divider，16:9）
> 「{章节名}过渡页背景，{风格}，单一主体图形，右侧留白放标题，{配色}，无文字」

### 内容配图（content，16:9）
> 「{概念}概念插画，扁平风格，{主体}，{配色}，横向构图，简洁，无文字，无人物面部特写」

### 图标/logo（square，1:1）
> 「{物体}扁平图标，纯色底或透明底，圆角，极简，居中，无文字，无背景杂乱」

### 页眉横条（banner，3:1）
> 「横向渐变横幅，{配色}，抽象线条，左重右轻，留白，无文字」

### 竖版（portrait，9:16）
> 「{主题}竖版插画，{风格}，自上而下构图，{配色}，留白，无文字」

## 避坑清单

- **图中文字**：主流模型常在图中生成乱码/错字。提示词务必加「无文字/without text」，重要文字回文档用文本框排版。
- **版权与在世人物**：避免「梵高风格、吉卜力风格、某在世艺术家风格、某品牌 logo、某公众人物」；商用前确认模型服务条款与素材授权。
- **手部/细节**：需要人物时写「全身/半身、简单手势」，避免「特写手指」类高翻车构图。
- **配色**：明确主色（如「深蓝 + 青 + 白」），与文档主题色一致，别让 AI 自由发挥出突兀色块。
- **比例**：宽图（banner/title）提示词写「横向构图/landscape」；竖图写「纵向构图/portrait」，避免主体被裁。
- **一致性**：多图同一风格，固定「风格句 + 配色句 + seed」反复用，保证整套 PPT 视觉统一。

## 图生图 / 局部重绘提示词

- 图生图（改风格）：`改成{扁平/水彩/3D/线稿}风格，保持构图不变，{配色}` + `--image src.png`
- 局部重绘：`把{某区域}替换为{新内容}，其余保持不变` + `--image src.png --mask mask.png`（mask 非透明区=重绘区）

**用法示例**（dark-tech 风格 PPT 封面）：
```
python scripts/imagegen.py generate --backend pollinations --layout title --prompt "AI战略发布会封面，暗色科技风，深蓝黑底+青蓝光效线条，发光网格，居中留白，无文字" --out cover.png
```

**换风格重做配图**：文档换 `style_id` 时，用新风格句重新生成配图；图生图快速方案：`改成{新风格句}，保持构图不变` + `--image 旧图.png`。

## 生图前必查

1. 用途（封面/配图/图标/背景）→ 选对版式。
2. 目标文档的配色与风格 → 写进提示词。
3. 是否需要图中文字 → 不需要就写「无文字」。
4. 是否有版权/肖像风险 → 有就换表述。
